# Engineering Documentation

This directory records the current frontend architecture, operational conventions, and architectural decisions for the Glass marketing site (this repo, deployed at **glasspay.app**). Statements about the current system are based on this repository. Sections labeled proposed or future describe follow-up work and are not implemented by the current sprint.

This structure intentionally mirrors `glass-waitlist` (the application repo) — the same docs layout, the same ADR format, the same CI gates. The two-repo relationship is spelled out in the [root README](../README.md); read it before touching any landing-page component.
